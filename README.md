## 📌 Tentang Repositori

`storage-public` digunakan untuk menyimpan dan melayani berbagai berkas media statis (gambar, logo, dokumen, font, dll.) agar dapat diakses publik melalui URL kustom GitHub Pages dengan cepat dan efisien.

---

## 📁 Struktur Direktori

```text
storage-public/
├── assets/
│   ├── images/          # Foto, banner, dan artwork
│   ├── logos/           # Logo brand, ikon, dan favicon
│   └── docs/            # Dokumen publik (PDF, panduan, dll)
├── index.html           # Halaman landing/katalog sederhana (opsional)
├── .gitignore
├── LICENSE
└── README.md
```
